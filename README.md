# Homebrew Tap (`michaelstonis/tap`)

Official [Homebrew](https://brew.sh) tap for macOS applications maintained by [Michael Stonis](https://github.com/michaelstonis).

## Available Casks

### [Past Due](https://github.com/michaelstonis/Past-Due)
Software update checker and installer for macOS applications (community-maintained continuation of [Latest](https://github.com/mangerlahn/Latest)).

```bash
brew install --cask michaelstonis/tap/past-due
```

To upgrade later:

```bash
brew upgrade --cask past-due
```
